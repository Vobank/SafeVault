СЕЙФ — личный шифровальщик файлов и заметок
============================================

ЧТО ЭТО
  Программа шифрует твои файлы и тексты так, что без мастер-пароля
  их невозможно прочитать. Используется AES-256-GCM — тот же класс
  шифрования, что в банках и мессенджерах. Ключ получается из пароля
  через scrypt (стойкий к перебору).

КАК ЗАПУСТИТЬ
  Двойной клик по файлу  "Запустить Сейф.bat"
  (при первом запуске он сам поставит нужную библиотеку — нужен
   установленный Python, можно взять с python.org)

КАК ПОЛЬЗОВАТЬСЯ
  1. Ввести мастер-пароль сверху.
  2. Вкладка "Файлы":
       - Зашифровать файл  -> рядом появится копия с .sejf
       - Расшифровать .sejf -> вернётся исходный файл
       (можно включить "удалять исходный после шифрования")
  3. Вкладка "Заметка":
       - пишешь текст (пароли, коды) и жмёшь "Зашифровать текст"
       - получается строка, которую можно хранить где угодно
       - "Расшифровать текст" вернёт её обратно (с тем же паролем)

ВАЖНО
  * Пароль НИГДЕ не хранится. Забудешь — данные пропадут навсегда.
    Это не баг, а суть шифрования. Запиши пароль в надёжном месте.
  * Для каждого файла используется случайная соль и nonce —
    одинаковые файлы дают разный шифртекст (это правильно).
  * GCM проверяет целостность: подменённый файл не расшифруется.

ПРЕДУПРЕЖДЕНИЕ ПО БЕЗОПАСНОСТИ
  Шифрование защищает данные "в покое" (на диске, в облаке, на флешке).
  Оно НЕ защищает, если на ПК активный вирус/бэкдор: он увидит данные
  в момент, когда ты их расшифровал, и перехватит пароль с клавиатуры.
  Поэтому пользуйся Сейфом ТОЛЬКО на чистой системе.
